# Gàidhlig Path

A free, offline-capable Scots Gaelic learning app (PWA): skill path, SM-2 spaced repetition, cloze, Pimsleur-style audio drill, tap-to-translate reading, 255 words with LearnGaelic dictionary links.

Live: https://cybernomadactual.github.io/gaidhlig/

Install on iPhone: open in Safari → Share → Add to Home Screen. On Android: Chrome menu → Install app.

## Audio
- Native recordings (aran, baile, ciamar, dè, uisge, ìm) from Wikimedia Commons / Lingua Libre, speakers Knites and DaoineÈibhinn, CC0 or CC BY-SA 4.0 (ìm, baile are CC BY-SA 4.0; derived MP3s are shared under the same licence). Full credits are in the app's ⚙︎ Settings.
- All other words were synthesised with eSpeak NG's Scottish Gaelic (gd) voice. They're approximate and robotic; compare them with real speakers on LearnGaelic.
